# Identidade visual

O perfil usa o cenário Tokyo Rain do portfólio em https://gdsantana.dev.

- `tokyo-rain.png`: cópia de `portifolio/public/images/share/tokyo-rain.png`, gerada pelo script `portifolio/scripts/share-images.ts` com a cena de ascii.rest 0.4.0. Para atualizar o banner, regenere no portfólio e copie o PNG para cá.
- Paleta de `portifolio/src/styles/global.css`: fundo `#0c0d12`, superfície `#171924`, texto `#f1f3f9`, texto secundário `#8d93a8`, destaque `#ff4b93`, ciano `#00f0ff` e azul `#38bdf8`.
- A cena usa ascii.rest; sua licença está em `ascii-rest-LICENSE.txt`.

O banner fica versionado para não depender de um gerador externo. Badges e gráficos continuam sendo imagens de serviços externos; sua disponibilidade depende desses serviços. O conteúdo principal permanece em Markdown.
